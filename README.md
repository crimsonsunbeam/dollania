# Доллания — виртуальное государство

Репозиторий содержит бота ВК и сайт.

## Структура

- `bot/` — бот ВК (Python + vk_api + Turso)
- `site/` — сайт (HTML + CSS)

## Настройка

1. Скопируйте `.env.example` в `bot/.env` и заполните токены
2. Установите зависимости: `cd bot && pip install -r requirements.txt`
3. Запустите бота: `cd bot && python main.py`

## Сайт

Открывается как `site/index.html` или на GitHub Pages.
